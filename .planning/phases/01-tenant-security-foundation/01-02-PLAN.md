## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deployment config → API process | Env vars decide the DB role, test-auth exposure and CORS; misconfiguration crosses here |
| API → PostgreSQL | The role the pool connects as decides whether RLS can be bypassed |
| client → API | Requests that end mid-flight or fail inside a handler must not leave transactions open or half-written |
