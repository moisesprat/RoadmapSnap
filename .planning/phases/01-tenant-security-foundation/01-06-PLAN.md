<objective>
Make dates round-trip without day shifts in any server timezone, by fixing the API's DATE contract at the driver and schema level and adapting the one client consumer.

Purpose: SEC-06 and D-15. RESEARCH Spike E showed that the default `pg` parser turns DATE into a midnight instant, which shifts by a day in Los Angeles and Kiritimati. The current DD/MM/YYYY formatter reads local getters, so it becomes a day-shift bug as soon as the string parser is registered. DATE values must travel as `YYYY-MM-DD` strings in both directions.
Output: `db/types.js`, `lib/dates.js` (`isoDateSchema`), ISO output from GET /workspaces/:id/projects, `dates.test.js`, `npm run test:tz` wired into CI, and the SPA adapter with its vitest.
</objective>
