<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → compose services | Env values from the root `.env` cross into containers; the api must receive only app-role credentials |
| developer machine → repository | Local secrets (`.env`, the dev private key) must never be committed or baked into images |
| dev-token → API | A local signing key is a trust anchor; it must stay local and be refused in production |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-33 | Information Disclosure | root `.env` and image contents | high | mitigate | Root `.gitignore` adds `.env`. `.dockerignore` excludes .env, .dev-keys, tests and scripts. Only `.env.example` files are tracked, with no real secrets |
| T-01-34 | Elevation of Privilege | api service DB credentials | high | mitigate | The api service gets only APP_DATABASE_URL (roadmapsnap_app), asserted on the rendered config. The boot check refuses a superuser URL (compose step 7) |
| T-01-35 | Information Disclosure | hard-coded app role password 'apppassword' (V4, compose) | medium | transfer | Known debt deferred to Phase 7 DEP-02 per CONTEXT "Deferred Ideas"; local-only skeleton |
| T-01-36 | Spoofing | dev-token private key | high | mitigate | Key stored in gitignored `.dev-keys/` with mode 0600; the printed JWKS is checked to contain no private members; the script refuses NODE_ENV=production, and the API refuses AUTH_TEST_JWKS under production |
| T-01-37 | Elevation of Privilege | container user | low | mitigate | `USER node` in the Dockerfile |
| T-01-38 | Information Disclosure | Postgres network exposure | low | mitigate | No host port mapping for postgres (asserted on the rendered config) |
| T-01-SC | Tampering | Docker base images (`postgres:16`, `node:24-alpine`) and `npm ci` in the image | medium | accept | Official images on major tags for a local skeleton. `npm ci --omit=dev` installs only the existing lockfile with no new packages. Digest pinning and image scanning belong to Phase 7 (DEP-06 secrets scan) |
