## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| working tree -> Docker build context | Everything in the context can be copied into an image layer |
| pull request -> CI | Workflow changes decide which checks run and whether a merge is blocked |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-05 | Denial of service (merge blocking) / Tampering | ci.yml path filters | medium | mitigate | ci.yml has no path filters, so shared-code changes always run Lite tests and a required Lite check can never sit "Pending"; guarded by tests/guards/ci-config.test.js |
| T-02-06 | Tampering | lockfile drift | low | accept | `npm ci` refuses an out-of-sync lockfile in every workflow and in the image; no extra control needed |
| T-02-SC | Tampering | npm installs | high | accept | No new package; only install commands and contexts change |
</threat_model>
